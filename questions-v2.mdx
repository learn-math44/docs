## What Can Questions V2 Do?

Questions V2 can generate math questions across **1,000+ topics**.

Topics can range from basic arithmetic to more advanced mathematics.

Examples include:

- Addition
- Subtraction
- Multiplication
- Division

And many more.

The topic library is designed to continue expanding as Math44 adds new curriculum areas.

## How Questions V2 Works

Questions V2 follows a simple process:

1. Choose a topic

Select what you want to practice.

For example:

Combining Like Terms

2. Choose your settings

Get X right total or Get X right in a row.

Click Generate Questions.

3. Practice, assign, or save

That's all! It's meant to be easy to use and understand. 

## Why Questions V2?

Traditional question creation can take a lot of time.

Questions V2 is designed to make the process much faster.

Instead of manually writing every problem, a teacher can select a topic and generate a fresh set of questions in seconds.

Questions V2 is also designed around Math44's existing learning experience instead of requiring users to leave Math44 and use another service or take time to make your own questions!

## Questions V2 vs. the Original Questions System

Questions V2 is a redesigned generation experience.

### Questions V1

The original system focused on making your own questions to use.

### Questions V2

Questions V2 expands the experience with:

- A redesigned interface
- 1,000+ available topics
- More generation settings
- Faster question creation
- Cleaner question previews
- Better organization
- More flexible question types
- Improved teacher workflow
- Math44's in-house AI generation

Questions V2 is intended to become the main question-generation experience across Math44.

## Does Questions V2 Use External AI?

No external AI website is required for the Questions V2 user experience.

Math44 generates questions through its own question-generation infrastructure and in-house AI.

## Final Product Goal

Questions V2 makes it easy to generate fresh math questions across 1,000+ topics using Math44's in-house AI, right inside Math44.
