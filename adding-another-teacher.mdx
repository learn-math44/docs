Go to ( [https://app.math44.org](https://app.math44.org) ).

<Frame>
  ![Teacher Dashboard Full](/images/teacher-dashboard-full.png)
</Frame>

Click your name at the bottom then click account settings. Then on the bar at the top click "Account Settings".

<Frame>
  ![Join A Class Panel](/images/join-a-class-panel.png)
</Frame>

Put in the class code that the class holder gives you.

<Note>
  This is the same class code your student put's in. Also the class holder will have to accept you.
</Note>
