First on your teacher dashboard please select "New Class".

<Frame>
  ![Teacher Dashboard Empty](/images/teacher-dashboard-empty.png)
</Frame>

You again will be prompted to create a class. Again, please select "New Class".

<Frame>
  ![Create Class Empty](/images/create-class-empty.avif)
</Frame>

You will need to fill in some information about your class. You will need a class name, subject, and a description. 

<Frame>
  ![Make A Class](/images/make-a-class.avif)
</Frame>

Your class has been made! Your students can join using that class code that is below the Class name. This class code is unique to your class.

<Frame>
  ![Class Page 1](/images/class-page-1.avif)
</Frame>
